# 東鐵駕駛室 3D 概念原型

此版本為真正 Three.js 3D 可操作原型，並**非**真實旺角東站的精確復刻。建築物是程序生成的香港風格示意模型，列車駕駛室也是初步幾何模型。

## 部署
將 `index.html` 放入 GitHub repository 根目錄，Settings → Pages → Deploy from a branch → main / (root)。完成後開啟 GitHub Pages 網址。

## 操作
- 手機：橫向操作，拖動畫面左右望，拖動動力滑桿加速，按住煞車減速。
- 電腦：W/↑ 增加動力，S/↓/空白鍵煞車，滑鼠拖動鏡頭。
- 按重置返回起點。

## 注意
首次載入需要網絡下載 Three.js（CDN）；不需 API Key。iOS Safari 全屏 API 可能受系統限制。未有測量路線、精確車站建築、正式列車模型或專業列車物理。
