# 東鐵綫｜旺角東司機室 靜態 Web App

這是由概念效果圖製成的靜態畫面，不是可駕駛的 3D 模擬器。畫面上的速度及儀表讀數屬圖片內容，不會更新。

## GitHub Pages 部署

將 `index.html`、`cab-scene.png`、`manifest.webmanifest` 上傳到 GitHub 儲存庫根目錄（不要只上傳 ZIP）。到 Settings → Pages → Build and deployment，選擇 Deploy from a branch、main、/(root)，儲存。稍候使用 GitHub Pages 網址開啟。

手機建議橫向觀看。部分 iPhone Safari 不支援網頁 Fullscreen API，按鈕可能不顯示；可用 Safari 分享 → 加入主畫面以獨立模式啟動。

圖片是 AI 概念設計，不保證建築、路線、儀表及車站配置符合現實。
