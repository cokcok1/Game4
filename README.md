# 東鐵綫 3D 司機室 V0.2

手機橫向使用，拖動 3D 畫面轉動視角；動力滑桿加速，長按煞車減速。嘗試於 125m 左右停車（容許誤差 ±16m），速度降至 0.5 km/h 以下即可開門。開門後要關門才可再次加速。

## 部署
將 index.html 放入 GitHub Pages repository 根目錄，設定 Settings → Pages → Deploy from a branch。使用 Three.js CDN，首次載入需要網絡。

## 限制
此版本是可操作 3D 技術原型，三路軌、島式和側式月台是概念性重建。軌道線形、地標尺寸、司機室儀表、車站比例和沿線建築尚未經現場測量校正，不能視為專業級寫實模擬。
